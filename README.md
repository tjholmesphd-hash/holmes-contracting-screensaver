# Holmes Contracting screensaver

Omarchy-style terminal screensaver. Holmes Contracting in braille.

Gmail will flag a `.bat` installer as a virus. It is not. Download the files from this repo instead.

## Install on Windows

1. On this page click **Code** (green) → **Download ZIP**.
2. Unzip the folder on the Windows PC.
3. Double-click **Install.bat**.
4. If SmartScreen appears: **More info** → **Run anyway**.
5. Set the wait time → **OK**.

That sets Holmes Contracting as the default screensaver. Mouse or any key exits.

Needs Microsoft Edge (already on Windows 10/11). No admin, Visual Studio, or Python.

## Files

- `screensaver.html` — the actual animation (safe to open in Edge, press F11 to preview)
- `Install.bat` — registers it as the Windows screensaver
- `OmarchyScreensaver.cs` — tiny host compiled on your PC by Windows itself
